# Connection Guide: Fastcode vs Remote-ID

Detailed guide for selecting, distinguishing, and authenticating remote connections in `awesun-cli`.

---

## 1. Fastcode & Verification Code vs Host List & Access Password

Understanding the distinction between temporary remote assistance and managed host connections is fundamental:

| Dimension                     | Fastcode & Verification Code (临时协助)                                                                                                                                                                                                         | Host List & Access Password (设备管理)                                                                                                                                                                                                                             |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Primary Scenario**          | **Temporary Remote Assistance** (C2C desktop help)                                                                                                                                                                                              | **Managed Device Control** (Unattended server/workstation access)                                                                                                                                                                                                  |
| **Device Ownership**          | **Unbound** to your AweSun account (temporary code from remote user)                                                                                                                                                                            | **Bound** to your AweSun account (appears in `device ls` table)                                                                                                                                                                                                    |
| **Identifier Source**         | **Fastcode (`--fastcode`)**: 9~10 digit numeric code shown on target client UI                                                                                                                                                                  | **Device ID (`--remote-id`)**: 9~10 digit numeric ID assigned upon account binding                                                                                                                                                                                 |
| **Authentication Credential** | **Verification Code (验证码)**:<br>1. Dynamic random code (4~6 alphanumeric chars) generated by client<br>2. Rotates upon client restart or manual refresh<br>3. **Passwordless option**: Use `--interactive` to let remote user click "Accept" | **Host Access Password (访问密码)**:<br>1. Fixed standalone password configured in client security settings<br>2. Persistent long-term credential designed for unattended login<br>3. **OS credential option**: Use `--username <user>` with host OS user password |
| **CLI Syntax**                | `session connect --type <type> --fastcode <CODE>`<br>`session connect --type <type> --fastcode <CODE> --interactive`                                                                                                                            | `session connect --type <type> --remote-id <ID>`<br>`session connect --type <type> --remote-id <ID> --username <USER>`                                                                                                                                             |
| **Credential Persistence**    | **Not cached / not supported**: Dynamic verification codes are one-time/ephemeral                                                                                                                                                               | **Supported**: Use `awesun-cli device grant` to save credentials locally for silent login                                                                                                                                                                          |
| **Interactive Acceptance**    | **Supported (`--interactive`)**: Remote user clicks popup "Accept" (60s timeout)                                                                                                                                                                | **NOT supported**: Unattended hosts require either access password or OS credentials                                                                                                                                                                               |

---

## 2. Fastcode vs Remote-ID Selection Signals

Pick the connection identifier strictly by the **SOURCE and CONTEXT** of the code provided:

| Signal                                                                                                       | Use                 | Reason                                                      |
| ------------------------------------------------------------------------------------------------------------ | ------------------- | ----------------------------------------------------------- |
| ID obtained from `device ls` / `device search` / `device info` output                                        | `--remote-id <ID>`  | Device is already bound to your account                     |
| ID provided in a share template (e.g. `我的识别码：507080482` / `使用向日葵即可对我发起远程协助`)            | `--fastcode <CODE>` | Unbound remote assistance code                              |
| ID is a bare 9~10 digit number stated by user (`识别码 507080482`, `远控 507080482`) with no matching device | `--fastcode <CODE>` | Remote assistance code; template formatting is not required |
| ID is a 9~10 digit code pasted by user, and `device info <ID>` returns `Remote not exists`                   | `--fastcode <CODE>` | Not in account device list => treat as fastcode             |
| User phrasing indicates assistance ("帮我远控一下", "快码是...", "帮我看看电脑")                             | `--fastcode <CODE>` | Remote assistance request pattern                           |
| User names a specific registered device ("my MacBook", "office server")                                      | `--remote-id <ID>`  | Managed device in account list                              |

---

## 3. Fastcode Format & Identification Rules

- A fastcode is a **9~10 digit numeric code** (e.g. `507080482`) displayed as `识别码` in the target's AweSun client. It is NOT bound to your account.
- A `remote_id` is also typically a **9~10 digit numeric ID** (e.g. `1738789907`) retrieved from `device ls` or established account device records.
- **Length cannot distinguish them**: Both can be 9~10 digits. Distinguish strictly by source/context, or verify by calling `awesun-cli device info <ID>`.
- **Do NOT require the share template**: Treat any bare 9~10 digit numeric code in a remote assistance context as a fastcode unless it resolves to a device in your account.

---

## 4. Decision Procedure

1. If the request mentions **识别码 / 快码 / 远程协助 / 验证码**, or provides an ID absent from your device list, use `--fastcode` (even if given as a bare number without the share template).
2. If the request includes the standard share template (`我的识别码：...` / `使用向日葵即可对我发起远程协助`), use `--fastcode` directly.
3. Otherwise, query the ID using `awesun-cli device info <ID>` or `awesun-cli device search <keyword>`.
4. If found in the device list => use `--remote-id`; if not found (`Remote not exists`) => use `--fastcode`.
5. NEVER retry a failed `--remote-id` connection as `--fastcode` (or vice versa) without verifying the origin of the identifier.

---

## 5. Connection Password & Authentication Rules

### 1) Remote Assistance (`--fastcode`)

- `awesun-cli session connect --type <type> --fastcode <CODE>`:
  Prompts for the target's **Verification Code (验证码)** shown on their client screen.
- `awesun-cli session connect --type <type> --fastcode <CODE> --interactive`:
  **NO password / verification code needed**. The CLI prompts the target machine with an authorization dialog: `"Waiting for remote acceptance... Times out after 60s if not accepted."` Once the target user clicks **Accept**, the connection succeeds.

### 2) Managed Host List (`--remote-id`)

- `awesun-cli session connect --type <type> --remote-id <ID>`:
  Prompts for the host's configured **Host Access Password (访问密码)**. If credentials were saved via `awesun-cli device grant --remote-id <ID> --password <pwd>`, connection proceeds automatically.
- `awesun-cli session connect --type <type> --remote-id <ID> --username <USER>`:
  Prompts for the host's **OS User Password (系统账号密码)**.

> [!WARNING]
> `--interactive` applies **ONLY** to `--fastcode` (remote assistance). Devices in your account list (`--remote-id`) do NOT support `--interactive` and must use host access passwords or system credentials.
